# Technical Mentorship 2026

</div>

Welcome to the Technical Mentorship 2026 repository by UPES ACM and ACM-W Student Chapters! This repository is designed to help you strengthen your programming fundamentals, improve logical thinking, and gain practical coding experience.

## Problem Statements

Solve the following **2 programming challenges** in C:

1. **Palindrome Number** – Write a program to check whether a given number reads the same forward and backward.

   **Example:** `121` is a palindrome, while `123` is not.

2. **Second Maximum Element** – Write a program to find the second-largest distinct element in a given array.

   **Example:** For the array `{10, 5, 20, 8, 20}`, the second maximum element is `10`.

## Submission Guidelines

1. Create a separate folder using your name. Use underscores instead of spaces if your name contains multiple words.
2. Save both C programs using the exact file names specified above.
3. Do not upload `.exe` files or other compiled binaries.
4. Commit your changes using meaningful commit messages.
5. Push your solutions to the designated GitHub repository.

## Important Note

This mentorship focuses on learning, consistency, and problem-solving. Make sure you understand your solutions instead of simply copying code. If you encounter an error, try debugging it before asking for help.
